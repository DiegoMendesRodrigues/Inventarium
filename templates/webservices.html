Webservices

A Necessidade da chave controla as permissões: “Alterar e visualizar alterações” autoriza GET, POST e PUT quando disponíveis; “Visualizar alterações” autoriza somente GET. Requisições sem permissão recebem 403.

GET
/resumo Retorna o resumo dos ativos cadastrados
Autenticação: Bearer Token Parâmetros: Nenhum Códigos de Resposta (Status Codes): Em caso de sucesso (200 OK) ou erro (401 ou 403) Corpo da Requisição (Payload): - Formato: JSON - Informações: Resumo dos ativos cadastrados, separados dentre as empresas cadastradas no sistema
GET
/ativos Retorna todos os ativos cadastrados
Autenticação: Bearer Token Parâmetros: Nenhum Códigos de Resposta (Status Codes): Em caso de sucesso (200 OK) ou erro (401 ou 403) Corpo da Requisição (Payload): - Formato: JSON - Informações: Todos os os ativos cadastrados no sistema, com as informações detalhadas de cada um deles
GET
/informacoes Retorna as informações utilizadas nos cadastros dos ativos, como inf_disco_tamanho, inf_hacks, inf_impressoras, inf_memorias_ram_qtde, inf_memorias_ram_tipo, inf_nobreaks, inf_perifericos, inf_perifericos_computador, inf_placa_mae_desktop, inf_placa_mae_notebook, inf_placa_mae_servidor, inf_placa_rede, inf_placas_de_video, inf_processadores_desktop, inf_processadores_notebook, inf_processadores_servidor, inf_servidores, inf_so_desktop, inf_so_servidores, inf_sofwares_licencas, inf_tablets_marcas, inf_tamanho_monitor, inf_televisao_marca
Autenticação: Bearer Token Parâmetros: Nenhum Códigos de Resposta (Status Codes): Em caso de sucesso (200 OK) ou erro (401 ou 403) Corpo da Requisição (Payload): - Formato: JSON - Informações: Todos as informações que estão nas tabelas auxiliares utilizadas no registro dos ativos, como os processadores, memória RAM, tamanho dos discos para armazenamento, marcas de placas mãe, resoluções de monitores, dentre outras
POST
/informacoes Criar um novo registro possuindo uma informação que será utilizada no cadastro de ativos
Autenticação: Bearer Token Parâmetros: - tabela_informacoes (string): sendo uma das seguintes tabelas: inf_disco_tamanho, inf_hacks, inf_impressoras, inf_memorias_ram_qtde, inf_memorias_ram_tipo, inf_nobreaks, inf_perifericos, inf_perifericos_computador, inf_placa_mae_desktop, inf_placa_mae_notebook, inf_placa_mae_servidor, inf_placa_rede, inf_placas_de_video, inf_processadores_desktop, inf_processadores_notebook, inf_processadores_servidor, inf_servidores, inf_so_desktop, inf_so_servidores, inf_sofwares_licencas, inf_tablets_marcas, inf_tamanho_monitor, inf_televisao_marca - nome (string): sendo a informação que será adicionada, como por exemplo, em inf_placa_mae_desktop adicionar ASUS Códigos de Resposta (Status Codes): Em caso de sucesso (201 Created) ou erro (400, 401 ou 403) Corpo da Requisição (Payload): - Formato: JSON - Informações: identificador do registro adicionado
PUT
/informacoes Alterar um registro de uma informação que é utilizado no cadastro de ativos
Autenticação: Bearer Token Parâmetros: - tabela_informacoes (string): sendo uma das seguintes tabelas: inf_disco_tamanho, inf_hacks, inf_impressoras, inf_memorias_ram_qtde, inf_memorias_ram_tipo, inf_nobreaks, inf_perifericos, inf_perifericos_computador, inf_placa_mae_desktop, inf_placa_mae_notebook, inf_placa_mae_servidor, inf_placa_rede, inf_placas_de_video, inf_processadores_desktop, inf_processadores_notebook, inf_processadores_servidor, inf_servidores, inf_so_desktop, inf_so_servidores, inf_sofwares_licencas, inf_tablets_marcas, inf_tamanho_monitor, inf_televisao_marca - codigo (string): sendo o identificador do registro que será alterado na tabela - nome (string): sendo a informação que será alterada, como por exemplo, em inf_placa_mae_desktop alterar ASUS para ASRock Códigos de Resposta (Status Codes): Em caso de sucesso (201 Created) ou erro (400, 401 ou 403) Corpo da Requisição (Payload): - Formato: JSON - Informações: identificador do registro adicionado
